# Portmanteau

Portmanteau word maker: blend two words (smoke + fog = smog), rank pairs, try brand-name mode, and vote in blend battles. Free tool.

## Features
- Word blender using the classic A-beginning + B-ending rule, with ranked multi-pair results
- Brand-name mode with syllable breakdown for naming brainstorms
- Blend battle: pit two blends against each other and vote for the winner
